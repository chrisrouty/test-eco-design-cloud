# Eco Design Cloud

Starter React pour un entretien technique front-end.

---

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- TanStack Query
- TanStack Table
- React Router
- Lucide Icons
- ESLint
- Yarn 4

---

## Prérequis

- Node.js 20 ou plus
- Yarn 4

## Installation

```bash
yarn install
```

## Lancement

```bash
yarn dev
```

L'application est disponible par défaut sur :

```txt
http://localhost:5173/
```

## Scripts

```bash
yarn dev
yarn build
yarn lint
yarn preview
```
